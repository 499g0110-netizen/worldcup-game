# v2 進度報告

## 測試環境
- 雲端容器，4 核 CPU、15 GB RAM，**沒有 GPU**；Chromium（Playwright）+ SwiftShader 軟體渲染。
- 在這個環境裡只有 0.3–0.4 fps，**不能代表一般電腦的效能**。FPS、幀時間在實機上還沒量測；按 F3 會在畫面上方顯示實測數字。

## 示範區比對結論（誠實版）
- **有改善**：石材從平滑磁磚改成粗面灰色花崗岩，石塊有破碎邊緣，銅像會坐在石緣、小腿垂下。
- **還差很多**：
  - 銅像是用 metaball 雕出來的，五官、鬍鬚、毛皮細節都不夠，近看不像照片。要達到照片等級，需要掃描模型或請人建模。
  - 參考相機角度沒有完全對齊照片，第 4–7 輪調整都沒有變好，目前用第 3 輪的設定。
  - 牆面的磚石比例、溼地面反光也還沒對上。

## 尚未完成
- 下車／離開車輛的自動化測試只做了腳踏車；汽車下車在測試中因為先倒車而沒觸發。
- 上下車沒有專用動畫（目前是走到車邊再直接切換姿勢）。
- 階梯、坡道沒有實作（地面是平的）。
- 交通 AI、路人尚未搬到 v2。
- 其他地標（霍爾斯滕門、市政廳等）目前用 OSM 分件擠出，沒有手工細節。
