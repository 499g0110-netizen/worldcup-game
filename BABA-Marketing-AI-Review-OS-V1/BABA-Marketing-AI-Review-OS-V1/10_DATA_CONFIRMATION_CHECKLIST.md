# 待補資料與準確度確認表

下列內容在正式上線前需要由巴巴事業確認。

## 品牌
- 正式公司名稱與各品牌名稱
- 品牌使命、願景、核心價值
- Logo 最新版
- 標準色、字體、安全距離
- 可用／禁用語彙
- 對外語氣
- 公益、獎項與沿革的正式資料

## 行銷企劃部
- 組織與角色
- 實際簽核層級
- 哪些稿件須董事長／總經理核准
- 哪些須業務、工程、法務確認
- 標準工時是否採本文建議
- 緊急件定義
- 逾期與退件規則

## 建案
- 案名
- 地址
- 坪數
- 戶數
- 價格
- 工程進度
- 交通時間
- 公設與建材
- 可對外數據
- 禁止表述
- 聯絡資訊
- 最新版銷售說帖

## 媒體
- 各平台尺寸
- 常用媒體名單
- 截稿規範
- 輸出廠商規格
- 實際帆布、圍籬、燈箱尺寸
- 廣告帳戶政策案例

## AI
- 使用 OpenAI 或 Anthropic API
- 可接受單月費用
- 影片最大長度
- 是否允許公司資料傳送至外部 AI
- 哪些資料必須遮蔽
- 資料保存期限

## 建議確認方式

每項資料加上：
- status: confirmed / draft / outdated / prohibited
- owner
- source
- updated_at
- review_due_at
