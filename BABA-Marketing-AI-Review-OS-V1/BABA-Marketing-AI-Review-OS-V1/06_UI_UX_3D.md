# UI / UX 與 3D 動畫規格

## 視覺定位

企業級、理性、精緻、具建築感；不是電玩介面，也不是過度炫技。

## 首頁

- 深色或中性背景
- 中央抽象「AI 核心建築／知識核心」
- 粒子由分散聚合成品牌核心
- 滑鼠移動產生細微視差
- 登入卡片清楚可讀
- 動畫 3–5 秒內完成
- 提供 Skip Animation
- 行動裝置降級成輕量動畫

## 粒子消散融合

狀態：
1. 粒子散落
2. 緩慢匯聚
3. 形成核心幾何
4. 登入後粒子向兩側消散
5. 內容介面淡入

技術：
- React Three Fiber
- BufferGeometry
- ShaderMaterial
- GSAP timeline
- prefers-reduced-motion 支援

## 內頁

- 左側導覽
- 上方全站搜尋
- 中央工作區
- 右側審核摘要
- 問題嚴重程度使用圖示與標籤，不只靠顏色
- 原文與建議可並排比較
- 圖片可點擊標記區域
- 影片提供時間碼問題清單

## 效能底線

- 首屏不因 3D 超過合理載入時間
- 3D bundle 動態載入
- 行動裝置粒子量降低
- WebGL 不支援時顯示靜態版本
- 後台不使用重型 3D
