# 行銷企劃部標準工作流程

## 1. 社群圖文流程

需求單 → 目的與受眾 → 資料查核 → 文案初稿 → 視覺 Brief → 設計 → 圖文交叉審核 → 主管審核 → 修正 → 最終校對 → 排程 → 發布 → 成效紀錄

### 標準交付物
- 需求單
- 文案
- 主視覺
- 尺寸版本
- CTA
- 連結
- 排程資訊
- 核准紀錄

### 建議時程
- 單純貼文：1–2 工作日
- 一般活動：3–5 工作日
- 重要品牌議題：5–7 工作日
- 需拍攝：另加 5–10 工作日

## 2. 影片流程

需求 → 企劃 → 腳本 → 資料審核 → 分鏡 → 拍攝／素材 → 初剪 → 內容審 → 精剪 → 字幕校對 → 聲音與授權 → 主管核准 → 輸出 → 發布

### 建議時程
- 15–30 秒短片：3–5 工作日
- 60–90 秒形象短片：7–14 工作日
- 訪談片：10–20 工作日
- 大型品牌片：依專案排程

## 3. 大型輸出

現場丈量 → 媒體位置分析 → 文案層級 → 初稿 → 比例模擬 → 輸出規格確認 → 主管審核 → 廠商打樣 → 色樣確認 → 輸出 → 現場驗收 → 完工照歸檔

## 4. 新聞稿

議題確認 → 資料蒐集 → 訪談／引用 → 初稿 → 事實查核 → 品牌審查 → 法務風險 → 高階主管核准 → 媒體版本 → 發布 → 露出追蹤

## 5. 媒體計畫

Brief → 市場問題 → 目標與 KPI → 受眾 → 策略 → 渠道 → 預算 → 素材 → 時程 → 追蹤 → 優化 → 結案

## 6. AIO 文章

題目 → 搜尋意圖 → 資料來源 → 大綱 → 初稿 → 事實查核 → AIO 優化 → 品牌校對 → SEO 技術檢查 → 發布 → 收錄與引用追蹤 → 更新

## 7. 審核責任

製作者：內容正確與完整  
第一審：格式、錯字、規格  
第二審：策略、品牌、風險  
主管：是否符合目的與可對外發布  
法務／工程／業務：只在涉及其專業時簽核
